# Video Chat Microservice (WebRTC - LiveKit)

Sistem Video Chat mandiri dengan arsitektur SFU.

## Struktur Project:
- `apps/video-backend-manager`: Node.js (Express) untuk Token Generation.
- `apps/video-frontend-widget`: React (Vite) untuk UI Video Layer.

## Cara Menjalankan:
1. Jalankan LiveKit Server (Port 7880).
2. Jalankan Backend (Port 5000).
3. Jalankan Frontend (Port 5173).
